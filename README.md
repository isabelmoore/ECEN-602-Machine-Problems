
# ECEN-602 Machine Problems

ECEN-602 Computer Communication and Networking course focuses on the design, implementation, and analysis of modern computer networks. Core topics include:
- ISO/OSI seven-layer model as a systematic framework for network protocol design.
- Transport-layer protocols and application-layer services.

### Programming Assignments:
This repository contains all the Machine Problems for ECEN-602, with each machine problem organized in its subdirectory:   
1. TCP Echo Server and Client  
   A basic TCP service that echoes back whatever the client sends.

2. TCP Simple Broadcast Chat Server  
   A chat server that broadcasts each message to all connected clients.

3. TFTP Server  
   A UDP-based file transfer service for simple read/write operations.

4. HTTP Proxy Server  
   An intermediary HTTP service that parses and forwards client requests.
